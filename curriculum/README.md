# 番申产品运营课程详情

独立静态页面，访问路径 `/fanshen-course/curriculum/`。原有招生首页独立保留。

## 内容更新

课程数据集中在 `course-data.js`。按飞书最新版同步各模块的 `name`、`units` 及每个单元的 `title`、`sub`、`plan`（课程安排）、`practice`（实训内容）、`gain`（学员收获），同时更新 `updatedAt`。

`app.js` 从这份数据生成完整课程、目录和单元数量。正文与导出图片共用同一份内容，没有另一份需要单独维护的图片文案。更新后提交到 `main`，GitHub Pages 发布完成后网页即为新版本。本页面不会自动读取或修改飞书。

## 图片导出

页面右上角「导出完整 PNG」导出全部课程及页尾。导出布局固定为 1200px 宽，不包含导航和操作按钮；当图片超过浏览器安全尺寸时，等比例缩放整张图，保留所有内容。文件名为 `番申产品运营课程详情.png`。

导出库为本地提供的 html2canvas 1.4.1，按需加载，不依赖外部 CDN。许可证见 `vendor/html2canvas.LICENSE.txt`。

## 本地预览与检查

在仓库根目录用任意静态 HTTP 服务预览 `/curriculum/`。无需安装依赖或构建。检查桌面及手机排版、目录跳转，并点击导出按钮确认长图包含首末课程。
