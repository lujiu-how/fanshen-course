# 番申 AI 产品运营就业课 · 线上课程详情

独立静态页面，访问路径 `/fanshen-course/curriculum/`。手机单列排版，沿用招生 H5 的金色科技主视觉，展示课程安排和实训内容。

## 内容更新

课程以已确认的飞书文档最新版为准（https://lcnoup481m1k.feishu.cn/wiki/Ac7GwMHgmiIAgSkQce5ctv4Rnxh），通过已授权的飞书官方接口只读获取。用户通知更新后再同步，不定时抓取、不通过屏幕控制读取，也不修改源文档。凭证仅在本机运行时读取，不得写入本仓库。

公开展示数据集中在 `course-data.js`：模块包含 `name`、可选 `note`、`units`；每课包含源表编号 `number`、标题 `title`、课程安排 `plan`、实训内容 `practice`。两类正文均为精简字符串，不展示学员收获。更新数据时同步 `updatedAt`，保持与源表模块及课节对应，不将原始长文直接覆盖到页面数据中。

`app.js` 自动生成模块、课程和数量，课节展示编号在每个模块内从 01 开始；源表编号保留在数据中。网页和 PNG 共用数据。通过 GitHub API 提交到 `main` 后，由 GitHub Pages 发布。

## 图片导出

页面底部固定「下载课程详情图片」按钮，顶部不显示工具栏。点击后生成手机宽度的完整长图，仅包含 AI 产品运营主视觉、课程名称、口号、基础课程大纲和页尾，不包含实训说明和操作按钮。

电脑端在支持 File System Access API 时，点击即选择 PNG 保存位置，再生成并保存完整课程图片；取消选择不会生成或下载。其他桌面浏览器使用标准下载，保存位置遵循浏览器设置。文件写入失败会显示错误，不另行触发下载。

手机端保留原图片交互。支持文件分享的手机浏览器通过 Web Share API 分享 `image/png` 文件，用户在系统面板中选择微信或其他应用。首次生成后若用户手势已失效，预览弹窗里的「分享给好友」提供新的点击入口。不支持文件分享的浏览器显示长图供长按发送或保存，并提供 PNG 下载链接；网页不能直接指定微信联系人。

布局固定为 390 CSS px，默认以 2 倍清晰度输出 780px 宽的 PNG。高度随完整内容伸展；超过浏览器安全尺寸时等比例降低分辨率，保留首尾全部内容。文件名为 `番申AI产品运营就业课-线上课程详情.png`。手机浏览器若未自动下载，可使用生成后的图片链接打开并保存。

分享控制器、PNG 生成器和本地 html2canvas 1.4.1 均在点击后按需加载，不依赖外部 CDN。生成结果缓存在当前页面内，关闭弹窗后可再次使用。html2canvas 许可证见 `vendor/html2canvas.LICENSE.txt`。

两端使用同一个主视觉与金色科技风格。主视觉顶部不再展示 Logo、品牌名或品牌说明；后续内容同步时保持该展示规则，页尾品牌与网站图标保留。手机为单列长图布局，760px 起适配宽屏：主视觉按 3:2 原比例铺满内容区宽度，课程介绍居中接在图片下方，课程安排与实训分栏。PNG 始终为 390px 手机布局。手机使用 960 × 640 的 `hero.webp` 优化版本；宽屏复用仓库根目录的 1536 × 1024 原主视觉 `hero-ai-product-operations-career.0550bcef70ce.webp`，保持清晰且不重复存储图片。分屏预加载与图片选择保持一致。样式、脚本、图片引用带内容版本参数；内容更新后，发布前需同步刷新引用版本，避免沿用旧缓存。

## 本地预览与检查

在仓库根目录用任意静态 HTTP 服务预览 `/curriculum/`。无需安装依赖或构建，宽屏图片复用仓库根目录资源，其余依赖均在此目录内。

检查桌面和手机排版，无横向溢出、底部按钮不遮挡页尾；核对模块及课节数量；点击下载按钮，确认主视觉、首末课程完整，实训说明和页面按钮未进入长图。验证电脑端保存位置选择及标准下载、手机文件分享与预览保存、用户取消和失败重试。
