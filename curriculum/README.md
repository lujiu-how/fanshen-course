# 番申产品运营课程详情

独立静态页面，访问路径 `/fanshen-course/curriculum/`。手机单列排版，沿用招生 H5 的金色科技主视觉，展示课程安排和实训内容。

## 内容更新

课程以飞书表格最新版为准，通过已授权的飞书官方接口只读获取。用户通知更新后再同步，不定时抓取、不通过屏幕控制读取，也不修改源表格。凭证仅在本机运行时读取，不得写入本仓库。

公开展示数据集中在 `course-data.js`：模块包含 `name`、可选 `note`、`units`；每课包含源表编号 `number`、标题 `title`、课程安排 `plan`、实训内容 `practice`。两类正文均为精简字符串，不展示学员收获。更新数据时同步 `updatedAt`，保持与源表模块及课节对应，不将原始长文直接覆盖到页面数据中。

`app.js` 自动生成模块、课程和数量，课节展示编号在每个模块内从 01 开始；源表编号保留在数据中。网页和 PNG 共用数据。通过 GitHub API 提交到 `main` 后，由 GitHub Pages 发布。

## 图片导出

页面右上角「导出课程 PNG」生成手机宽度的完整长图，仅包含品牌主视觉、基础课程大纲和页尾，不包含实训说明、工具栏和操作按钮。

布局固定为 390 CSS px，默认以 2 倍清晰度输出 780px 宽的 PNG。高度随完整内容伸展；超过浏览器安全尺寸时等比例降低分辨率，保留首尾全部内容。文件名为 `番申产品运营课程详情.png`。手机浏览器若未自动下载，可使用生成后的图片链接打开并保存。

导出库为本地提供的 html2canvas 1.4.1，按需加载，不依赖外部 CDN。许可证见 `vendor/html2canvas.LICENSE.txt`。

## 本地预览与检查

在仓库根目录用任意静态 HTTP 服务预览 `/curriculum/`。无需安装依赖或构建。主视觉复用仓库根目录的 `hero-ai-product-operations-career.0550bcef70ce.webp`，部署时保留相对位置。

检查桌面和手机排版，无横向溢出；核对模块及课节数量；点击导出按钮，确认主视觉、首末课程完整，实训说明和页面按钮未进入长图。
